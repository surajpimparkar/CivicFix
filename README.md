# CivicFix

Full-stack CivicFix hackathon website for Windows 10/11 and Node.js 24.

## Run backend
Open VS Code terminal:

    cd backend
    npm install
    npm start

Backend: http://localhost:5000

## Run frontend
Open a second VS Code terminal:

    cd frontend
    npm install
    npm run dev

Frontend: http://localhost:5173

Keep both terminals running.
